### 1) **Spring Cloud Sleuth가 Spring Cloud 최신 릴리즈 트레인에서 제거됨**

Spring Cloud Sleuth는 **Spring Cloud 2022.0** 이상의 릴리즈 트레인에서 더 이상 포함되지 않습니다. 이 트레인은 Sleuth 대신 **Micrometer Tracing** 을 사용하도록 변경되었기 때문입니다

## 1️⃣ 예전 구조 (Spring Boot 2.x + Sleuth)

과거에는:

  * spring-cloud-starter-sleuth
  * spring-cloud-starter-zipkin



이렇게만 넣으면 자동으로

> Sleuth → Brave → Zipkin

구조로 동작했어.

Sleuth가 내부적으로 **Brave를 사용했고** , Brave가 Zipkin으로 span을 전송했지.

zipkin과 연동하기 위해서 서비스 설정파일 application.yml 에 zipkin 서버를 연동
    
    
    zipkin:
      base-url: http://localhost:9411
      enabled: true
    sleuth:
      sampler:
        probability: 1.0

## 2️⃣ 지금 구조 (Spring Boot 3.x 이상)

Spring Boot 3부터는 **Sleuth가 제거** 됐어.  
대신 구조가 이렇게 바뀜:

> Micrometer Tracing → Brave → Zipkin

여기서 핵심이 👇

### micrometer-tracing-bridge-brave

이게 예전 Sleuth가 하던 역할을 대신하는 “브리지”야.

즉:

  * Micrometer Tracing API
  * Brave 구현체 연결
  * Brave가 Zipkin으로 span 전송


    
    
    <!-- Micrometer Tracing + Brave -->
    <dependency>
       <groupId>io.micrometer</groupId>
       <artifactId>micrometer-tracing-bridge-brave</artifactId>
    </dependency>
    
    <!-- Zipkin 전송 -->
    <dependency>
       <groupId>io.zipkin.reporter2</groupId>
       <artifactId>zipkin-reporter-brave</artifactId>
    </dependency>

따라서 zipkin dependency는 사용하지 않고 brave dependency가 zipkin에 전송해준다.

Micrometer Tracing → Brave → Zipkin

application.yml 에서 zipkin 연동 
    
    
    management:
      tracing:
        enabled: true
        sampling:
          probability: 1.0   # 예전 sleuth.sampler.probability 대체
    
      zipkin:
        tracing:
          endpoint: http://localhost:9411/api/v2/spans
    

  * **management.tracing.enabled**   
→ 트레이싱 활성화
  * **management.tracing.sampling.probability**  
→ Sleuth의 sleuth.sampler.probability 대체  
→ 1.0 = 100% 수집
  * **management.zipkin.tracing.endpoint**  
→ Zipkin API v2 endpoint  
→ 반드시 /api/v2/spans 포함

# feign-micrometer

Spring Boot 3 + Micrometer Tracing 환경에서 Feign이 tracing 전파를 하려면 내부적으로 MicrometerObservationCapability 가 Feign에 등록되어야 한다. 그걸 실제로 제공하는 모듈이 바로 io.github.openfeign:feign-micrometer 이다.

이게 없으면, Feign 호출 - > Zipkin exporter는 동작 하지만,  
❌ Feign이 trace header를 실어주지 않는다  
❌ 그래서 traceId가 달라진다

TraceId :699a829552905d3da718252ab0a02fc8 가 일치.

모든 회계 거래는 **전표 - > 승인 -> 전기 -> 장부 반영** 구조라고 생각한다.

거래가 발생하면 전표를 입력하고 전표에 대한 검증을 한 뒤, 결재/승인을 받고 전기 과정을 거쳐 총계정원장/재무제표에 반영된다.

**_전표처리?_**

**전표가 만들어 진다는 것은 차변과 대변의 금액과 계정과목을 입력하여 회계거래를 기록하는 것** 을 의미한다.

이때 차변의 **금액의 합 = 대변의 금액의 합** 이여야 하는데 이를 복식부기 원리라 한다. 

**_차변_** : 자산증가 / 비용 발생 내용 

**_대변_ :** 자산 감소 / 수익 발생 내용 

_**계정과목 이란 ?**_ 돈의 성격을 분류하는 코드이다.
    
    
    자산 현금/보통예금 /외상 매출금 / 재고자산/ 건물 / 비품
    부채 외상매입금 / 차입금 / 미지급금
    자본 자본금 / 이익잉여금
    수익 매출 / 이자수익 
    비용 급여 / 접대비 / 임차료 / 광고비

_**회계단위란**?_ 회사 내부에서 회계를 나누는 조직을 의미한다.

어음 : 미래에 돈을 지급하겠다는 약속 문서이다. 언제 얼마를 지급해야하는지에 대해서 어음적수 현황표에서 확인이 가능하다.

**_전기 ?_**

전표 데이터를 총계정원장GL /보조원장에 반영하는 작업으로 이 단계 에서 전표번호가 최종 확정 채번된다. 

_**분개처리란?**_

어떤 계정이 증가했고 어떤 계정이 감소했는지 차변 / 대변 으로 나누어 기록하는 과정을 의미한다.

_**역분개 ?**_

돈이 나간 시점이 아니라 비용/수익이 발생한 시점에 회계를 기록한다.

따라서 결산 시점에 임시 분개를 만들고 다음달에 역분개를 진행합니다.(자동취소와 의미가 비슷)

**\- 사례:** 12월에 미지급된 급여를 비용처리(결산 분개)하고, 1월 1일에 이를 취소(역분개)하여 실제 급여 지급 시 중복 계산되지 않게 하는 로직.

_**역분개 프로세스**_

결산 분개 생성 -> 역분개 대상 체크여부 확인 - 역분개 예정일 - 배치 스케줄러 적용 

\- 역분개 전표 자동 생성 - 차변/대변 SWAP - 전표 저장 - 전기 - 원장 반영 .

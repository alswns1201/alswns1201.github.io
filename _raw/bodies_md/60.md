springboot 의 컨슈머 application.properties 설정.
    
    
    server.port=0 -- 로컬에서 현재 8080이 띄어져있음으로 현재 띄울수 있는 포트를 알아서 띄어주는 옵션 0 
    spring.kafka.bootstrap-servers=[AWS EC2 서버 IP PORT]
    spring.kafka.consumer.key-deserializer=org.apache.kafka.common.serialization.StringDeserializer
    spring.kafka.consumer.value-deserializer=org.apache.kafka.common.serialization.StringDeserializer
    spring.kafka.consumer.auto-offset-reset=earliest

테스트 컨트롤러 : email.send 메세지를 주기적으로 체크하기 위한 리스너 등록.(**@KafaListener**)
    
    
    package com.example.consumer;
    
    
    import lombok.extern.slf4j.Slf4j;
    import org.springframework.kafka.annotation.KafkaListener;
    import org.springframework.stereotype.Service;
    
    @Slf4j
    @Service
    public class EmailSendConsumer {
    
        /**
         * consumer 가 email.send를 계속 주기적으로 체크하면서, groupId로 읽어 드린다.
         * @param message
         */
        @KafkaListener(topics = "email.send",groupId = "eamil-send-group")
        public void consumer(String message){
            log.info("kafka message {} ", message);
    
            EmailSendMessage emailSendMessage = EmailSendMessage.fromJson(message);
    
            log.info("success");
        }
    }

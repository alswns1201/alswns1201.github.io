## 자식컴포넌트 제어 useImperativeHandle과 forwardRef

React의 철학은 부모가 props를 통해 자식에게 데이터를 전달하고, 자식은 이 props를 받아 렌더링하는 단방향 데이터 흐름에 기반합니다. 하지만 때로는 부모 컴포넌트에서 자식 컴포넌트의 특정 메서드를 직접 호출하거나, 자식 컴포넌트 내부의 DOM 요소에 접근해야 하는 "예외적인" 상황이 발생합니다. 이때 ref와 함께 forwardRef, useImperativeHandle 등이 사용됩니다.

forwardRef: ref를 자식 컴포넌트에 전달하기

useImperativeHandle: ref를 통한 자식 노출 제어

### forwardRef: ref를 자식 컴포넌트에 전달하기

기본적으로 함수형 컴포넌트는 ref를 직접 받을 수 없습니다. ref를 사용하여 자식 컴포넌트의 내부 DOM 요소나 컴포넌트 인스턴스에 접근하려면 forwardRef를 사용해야합니다. forwardRef는 부모로부터 전달받은 ref를 실제 DOM 요소나 다른 자식 컴포넌트에 "전달(forward)"해주는 역할을 합니다.
    
    
    // BottomToast.js (자식 컴포넌트)
    import React, { useRef, useCallback, forwardRef, useImperativeHandle } from 'react';
    
    function BottomToast(props, propRef) { // propRef가 forwardRef를 통해 전달됨
        const toastPopupRef = useRef(null); // 실제 DOM 요소에 연결될 ref
        const overlayRef = useRef(null);
        const [texts, setTexts] = useState([]); // 토스트 메시지 상태
    
        const openToastPopup = useCallback(() => {
            if (toastPopupRef.current && overlayRef.current) {
                toastPopupRef.current.style.display = 'block';
                overlayRef.current.style.display = 'block';
    
                setTimeout(function () {
                    toastPopupRef.current.style.transition = 'transform 0.3s ease-out, opacity 0.3s ease-out';
                    toastPopupRef.current.style.transform = 'translateY(0)';
                    toastPopupRef.current.style.opacity = '1';
                }, 0);
            }
        }, []);
    
        const closeToastPopup = useCallback(() => {
            if (toastPopupRef.current && overlayRef.current) {
                toastPopupRef.current.style.transition = 'transform 0.3s ease-in, opacity 0.3s ease-in';
                toastPopupRef.current.style.transform = 'translateY(100%)';
                toastPopupRef.current.style.opacity = '0';
                setTimeout(() => {
                    toastPopupRef.current.style.display = 'none';
                    overlayRef.current.style.display = 'none';
                }, 300); // 애니메이션 시간과 맞춤
            }
        }, []);
    
        // useImperativeHandle: 부모에게 노출할 메서드를 정의
        useImperativeHandle(propRef, () => {
            return {
                openToastPopup: (textList) => {
                    if (textList instanceof Array) {
                        setTexts(textList);
                    } else {
                        const textArr = [];
                        textArr.push(textList);
                        setTexts(textArr);
                    }
                    openToastPopup(); // 내부 openToastPopup 함수 호출
                },
                closeToastPopup: () => {
                    closeToastPopup(); // 내부 closeToastPopup 함수 호출
                }
            };
        });
    
        return (
            <>
                <div ref={overlayRef} ></div>
                <div ref={toastPopupRef} >
                    {texts.map((text, index) => (
                        <p key={index}>{text}</p>
                    ))}
                    <button onClick={closeToastPopup}>닫기</button>
                </div>
            </>
        );
    }
    
    export default forwardRef(BottomToast); // forwardRef로 컴포넌트 래핑

여기서 저번 포스트에 언급한 useCallback 에 대해서 다시 언급해보겠습니다.openToastPopup 이나 closeToastPopup 은 useCallback을 사용하여 의존성 배열은 [] 을 적용하고 있습니다. 이는 이 함수가 컴포넌트가 처음 마운트될 때 단 한 번만 생성되고, 그 이후에는 컴포넌트가 아무리 리렌더링되어도 동일한 함수 인스턴스를 반환한다는 것을 의미합니다. 이 함수는 외부(부모 컴포넌트)로 useImperativeHandle을 통해 노출되기 떄문에 useCallback을 이용하였습니다.

useImperativeHandle도 두 번째 인자로 의존성 배열을 받습니다. 만약 useImperativeHandle 내에서 반환하는 객체({ openToastPopup: ..., closeToastPopup: ... }) 안에 useCallback으로 감싸지지 않은 함수(openToastPopup)가 있었다면, BottomToast 컴포넌트가 리렌더링될 때마다 openToastPopup 함수 자체가 새로운 인스턴스로 생성됩니다.

### useImperativeHandle: ref를 통한 자식 노출 제어

useImperativeHandle은 forwardRef와 함께 사용되며, 부모 컴포넌트에게 노출될 ref 객체의 내용을 사용자가 직접 정의할 수 있게 해주는 Hook입니다. 즉, 부모 컴포넌트가 ref를 통해 자식의 내부를 "엿볼" 때, 어떤 메서드나 속성만 보여줄지 명시적으로 제어하는 역할로 BottomToast.js 예시 에 useImperativeHandle을 보시면, 부모에게 openToastPopup 과 closeToastPopup 메서드만 노출하도록 정의했습니다. 부모는 이 ref를 통해 다른 내부 상태나 DOM에 직접 접근할 수 없고, 오직 정의된 메서드만 호출할 수 있습니다.

#### useImperativeHandle과 forwardRef의 관계: 둘은 한 몸!

함수형 컴포넌트에서 특정 메서드를 ref를 통해 부모에게 노출하려면 forwardRef와 useImperativeHandle을 함께 사용해야 합니다.

  * forwardRef: 부모 컴포넌트가 ref를 자식 컴포넌트로 "전달"할 수 있도록 길을 터주는 역할을 합니다. 이 길을 통해 부모는 자식 컴포넌트의 특정 부분(일반적으로 DOM 요소)에 접근할 수 있게 됩니다.
  * useImperativeHandle: forwardRef로 전달받은 ref를 통해 "어떤 내용"을 부모에게 노출할지 "정의"하고 "제어"하는 역할을 합니다. 기본적으로 ref는 DOM 요소에 직접 연결되지만, useImperativeHandle을 사용하면 DOM이 아닌, 특정 메서드나 커스텀 객체를 ref의 current 속성에 바인딩할 수 있습니다.



forwardRef는 ref를 받도록 컴포넌트를 가능하게 하고, 그 ref는 기본적으로 컴포넌트 내부의 가장 상위 DOM 노드에 직접 연결됩니다. 그러나 useImperativeHandle은 forwardRef로 전달받은 ref가 특정 DOM 노드가 아닌, 당신이 정의한 커스텀 객체(주로 메서드들을 담은 객체)를 가리키게 할 때 사용합니다. 즉, forwardRef가 없으면 useImperativeHandle 자체를 사용할 수 없습니다.

부모 컴포넌트에서 사용
    
    
    // ParentComponent.js
    import React, { useRef } from 'react';
    import BottomToast from './BottomToast'; // 위에서 만든 BottomToast 컴포넌트 임포트
    
    function ParentComponent() {
      const toastRef = useRef(null); // BottomToast 컴포넌트에 연결될 ref
    
      const showMyToast = () => {
        // ref를 통해 BottomToast의 openToastPopup 메서드 호출
        if (toastRef.current) {
          toastRef.current.openToastPopup(['환영합니다!', '오늘도 좋은 하루 되세요!']);
        }
      };
    
      const hideMyToast = () => {
        if (toastRef.current) {
          toastRef.current.closeToastPopup();
        }
      };
    
      return (
        <div>
          <h1>부모 컴포넌트</h1>
          <button onClick={showMyToast}>토스트 팝업 열기</button>
          <button onClick={hideMyToast}>토스트 팝업 닫기</button>
    
          {/* ref를 BottomToast 컴포넌트에 전달 */}
          <BottomToast ref={toastRef} />
        </div>
      );
    }
    
    export default ParentComponent;

이렇게 useImperativeHandle과 forwardRef를 함께 사용하면, 컴포넌트 간의 결합도를 낮추면서도 필요한 경우에만 자식 컴포넌트의 특정 기능을 제어할 수 있습니다.

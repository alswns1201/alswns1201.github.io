      curl -O https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.0.33/mysql-connector-j-8.0.33.jar"

참고로 CDC 와 차이를 구분하는것이 좋습니다.

가장 차이는 DB에 부하를 주느냐와 "삭제(DELETE)를 감지하느냐"입니다.

**비교 항목** | **JDBC Source Connector (일반)** | **Debezium (CDC 방식)**  
---|---|---  
**방식** | 일정 시간마다 SELECT 쿼리를 날림 | DB의 **로그(Binlog 등)**를 몰래 읽음  
**DB 부하** | 쿼리를 계속 날리므로 DB가 힘들어함 | 로그만 읽으므로 DB 성능 영향이 거의 없음  
**DELETE 감지** | **불가능** (행이 지워지면 쿼리에 안 잡힘) | **가능** (로그에 삭제 기록이 남으므로 감지)  
**데이터 추적** | 현재 데이터 상태만 알 수 있음 | 수정 전/후 데이터를 모두 알 수 있음  
  
  * **"로그 기반 CDC(Debezium 등)를 씁시다":** 실시간 결제, 서비스 간 데이터 동기화, 삭제 이벤트 처리가 중요할 때.
  * **"JDBC Source Connector를 씁시다":** 배치(Batch) 성격의 데이터 로드, 보안상 DB 로그 접근이 불가능할 때, 혹은 단순히 새로 추가되는(INSERT) 데이터만 관심 있을 때.

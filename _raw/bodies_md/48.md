### 1\. 스레드 기반 비동기

  * 여러 작업을 **동시에 처리** 하기 위해 각각 스레드를 할당함.
  * 예: Java에서 ExecutorService를 사용하면 CPU 코어나 스레드 풀 만큼 동시에 여러 작업을 처리 가능.
  * 특징: 
    * **병렬(parallel)** 처리 가능
    * CPU 집약적인 작업도 동시에 수행 가능
    * 스레드 수가 많아지면 **컨텍스트 스위칭 비용** 이 생김



* * *

### 2\. 이벤트 루프 기반 비동기

  * 단일 스레드에서 **작업을 순차적으로 처리** 하지만,
  * I/O나 타이머처럼 **결과가 나올 때까지 기다리지 않고 다음 코드 실행** 가능
  * 완료된 작업은 큐에서 가져와 처리
  * 특징: 
    * **순차적(sequential)** 실행 (CPU 연산 기준)
    * **I/O bound** 작업에 최적화
    * CPU 집약적인 작업이 길어지면 이벤트 루프가 막혀 다른 작업도 지연됨



* * *

### 3\. 차이를 그림으로 설명하면
    
    
    스레드 기반:           이벤트 루프 기반:
    
    Task1 ----> 작업 스레드1  Task1 ----> Call Stack
    Task2 ----> 작업 스레드2  Task2 ----> Call Stack (대기)
    Task3 ----> 작업 스레드3  Task3 ----> Call Stack (대기)
    
    [결과] 동시에 여러 작업 처리    결과 나오는 대로 처리, CPU 연산은 순차

  * **스레드 기반** = 동시에 여러 작업 처리 가능 → 병렬(parallel)
  * **이벤트 루프 기반** = 하나씩 순차적 처리 → 완료되는 즉시 실행 → 비동기(asynchronous)

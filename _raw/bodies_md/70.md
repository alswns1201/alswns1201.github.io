“RestTemplate 없이, 인터페이스만으로 API를 쓴다”

## 1️⃣ 왜 Feign Client인가

외부 API 연동을 직접 구현하면 보통 이런 코드가 나온다.
    
    
    RestTemplate restTemplate = new RestTemplate();
    ResponseEntity<UserDto> response =
        restTemplate.getForEntity("https://api.example.com/users/1", UserDto.class);

문제점:

  * URL 하드코딩
  * HTTP 로직이 서비스 코드에 섞임
  * 테스트/유지보수 불리
  * 공통 설정(헤더, 인증, 로깅) 중복



👉 **Feign Client는 이 문제를 “인터페이스”로 해결한다.**

* * *

## 2️⃣ Feign Client 핵심 개념

Feign은 **HTTP Client를 추상화한 선언적 클라이언트** 다.

> ✔️ 인터페이스 + 애노테이션  
> ✔️ 구현체는 런타임에 자동 생성  
> ✔️ URL만 알면 메서드 호출처럼 사용

구조적으로 보면:

Service → Feign Interface → 외부 API 

* * *

    }

## 4️⃣ Feign Client 기본 사용법

### 1) 외부 API 명세
    
    
    GET https://api.example.com/users/{id}

* * *

### 2) Feign Client 인터페이스 작성
    
    
    @FeignClient(
        name = "userApiClient",
        url = "${external.api.user}"
    )
    public interface UserApiClient {
    
        @GetMapping("/users/{id}")
        UserResponse getUser(@PathVariable("id") Long id);
    }

📌 **중요 포인트**

  * @FeignClient = 외부 API 정의
  * url은 설정 파일로 분리
  * 구현 클래스 ❌ → Spring이 자동 생성



* * *

### 3) application.yml
    
    
    external:
      api:
        user: https://api.example.com

* * *

### 4) DTO
    
    
    @Getter
    @NoArgsConstructor
    public class UserResponse {
        private Long id;
        private String name;
        private String email;
    }

* * *

### 5) 서비스에서 사용
    
    
    @Service
    @RequiredArgsConstructor
    public class UserService {
    
        private final UserApiClient userApiClient;
    
        public UserResponse getUser(Long id) {
            return userApiClient.getUser(id);
        }
    }

✅ **HTTP 호출 느낌 전혀 없음**  
✅ **그냥 메서드 호출**

* * *

## 5️⃣ POST / Header / Body 예제

### POST 요청
    
    
    @FeignClient(name = "orderApi", url = "${external.api.order}")
    public interface OrderApiClient {
    
        @PostMapping("/orders")
        OrderResponse createOrder(@RequestBody OrderRequest request);
    }
    
    
    @Getter
    @AllArgsConstructor
    public class OrderRequest {
        private String productCode;
        private int quantity;
    }

* * *

### Header 포함
    
    
    @GetMapping("/profile")
    ProfileResponse getProfile(

## 6️⃣ 공통 Header / 인증 처리 (실무 핵심)

### Feign Configuration
    
    
    @Configuration
    public class FeignConfig {
    
        @Bean
        public RequestInterceptor requestInterceptor() {
            return requestTemplate -> {
                requestTemplate.header("Content-Type", "application/json");
                requestTemplate.header("Authorization", "Bearer TOKEN");
            };
        }
    }
    
    
    @FeignClient(
        name = "secureApi",
        url = "${external.api.secure}",
        configuration = FeignConfig.class
    )
    public interface SecureApiClient {
    }

👉 **토큰, 공통 헤더, 추적 ID 전부 여기서 처리**

## 7️⃣ 예외 처리 (반드시 필요)

### Custom Error Decoder
    
    
    @Component
    public class FeignErrorDecoder implements ErrorDecoder {
    
        @Override
        public Exception decode(String methodKey, Response response) {
            return new RuntimeException("외부 API 호출 실패: " + response.status());
        }
    }
    
    
    @Bean
    public ErrorDecoder errorDecoder() {
        return new FeignErrorDecoder();
    }

## 8️⃣ 왜 “인터페이스 + URL” 구조가 좋은가

항목RestTemplateFeign  가독성 | 낮음 | 높음  
---|---|---  
테스트 | 어려움 | Mock 쉬움  
유지보수 | URL 분산 | 중앙 집중  
선언적 | ❌ | ✅  
  
👉 **외부 API = 포트(Interface)**  
👉 **비즈니스 로직과 완전히 분리**

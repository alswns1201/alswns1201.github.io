프리티어 t3 마이크로는 메모리가 1G -> 카프카를 실행시키기엔 너무 적다 .

* 강제로 메모리를 낮춰서 사용 - 메모리 400메가 로 제한 하여 실행.
    
    
    export KAFKA_HEAP_OPTS="-Xmx400m -Xms400m"

  
* 스왑을 활용하여 메모리를 디스크에서 활용

\- /swapfile에 2G 짜리의 파일을 생성

\- 권한 부여 

\- 메모리 공간으로서 사용 ( swap을 전환)

-swap 활성화 . 
    
    
    sudo dd if=/dev/zero of=/swapfile bs=128M count=16
    
    
    sudo chmod 600 /swapfile
    
    
    sudo mkswap /swapfile
    
    sudo swapon /swapfile

해당 인스턴스를 껐다 키더라도 위 설정이 반영 되도록 vi 설정

\- /swapfile swap swap defaults 0 0 
    
    
    sudo vi /etc/fstab

카프카 실행   
\- tar로 풀어둔 kafak_2.13-4.0.0 폴더에 들어와서 카프카 실행.

\- 카프카 실행을 할건데 config안에 server.properties 의 설정 파일을 적용할래 .

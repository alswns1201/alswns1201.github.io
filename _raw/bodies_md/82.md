### 1\. Spring boot 서비스의 metric을 적용하여 Prometheus와 적용 

Spring Boot 프로젝트에서 Prometheus 지표를 노출하려면 **Micrometer Prometheus 저장소** 의존성을 추가하고, **Actuator** 설정을 통해 엔드포인트를 열어주어야 합니다.

Spring Boot 애플리케이션의 지표를 수집하기 위해 spring-boot-starter-actuator와 이를 Prometheus 형식으로 변환해주는 micrometer-registry-prometheus가 필요합니다.
    
    
    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-actuator</artifactId>
        </dependency>
    
        <dependency>
            <groupId>io.micrometer</groupId>
            <artifactId>micrometer-registry-prometheus</artifactId>
        </dependency>
    </dependencies>

본적으로 보안상 닫혀 있는 Actuator 엔드포인트를 활성화하고, Prometheus용 경로를 노출합니다.
    
    
    management:
      endpoints:
        web:
          exposure:
            # prometheus 엔드포인트를 외부로 공개
            include: "prometheus, health, info"
      metrics:
        tags:
          # 대시보드에서 서비스별 구분을 위해 애플리케이션 이름 태그 추가
          application: ${spring.application.name}

**애플리케이션 실행:** 서비스가 기동되면 http://localhost:8000/actuator/prometheus 경로로 접속해 봅니다.

그후 프로메테우스를 실행하기 위한 yml을 구성합니다. 
    
    
    global:
      scrape_interval: 15s
    
    scrape_configs:
      # 1. user-service 설정
      - job_name: "user-service"
        metrics_path: "/user-service/actuator/prometheus"
        static_configs:
          - targets: ["host.docker.internal:8000"]
    
      # 2. apigateway-service 설정 (중복된 키 대신 항목으로 추가)
      - job_name: "apigateway-service"
        metrics_path: "/actuator/prometheus"
        static_configs:
          - targets: ["host.docker.internal:8000"]      
    
      # 3. order-service 설정
      - job_name: "order-service"
        metrics_path: "/order-service/actuator/prometheus"
        static_configs:
          - targets: ["host.docker.internal:8000"]

### 2\. 프로메테우스가 가져온 데이터를 Grafana에서 시각화 

시각화 하기 위해서 prometheus를 grafana 와 연동 합니다. 

Grafana에서 Prometheus를 연동하려면 **'Data Sources'** 메뉴에서 Prometheus를 선택하고, 도커 네트워크상의 서비스 주소(http://prometheus:9090)를 입력하면 됩니다. 또한 **Grafana Labs(Hub)**에서 제공하는 대시보드를 임포트(Import)하여 빠르게 시각화할 수 있습니다.

### Grafana Hub(Dashboard) 연동 및 임포트 방법

직접 대시보드를 만들기보다, 전 세계 사용자들이 만들어둔 **Grafana Labs Dashboard Hub** 의 템플릿을 가져오는 것이 효율적입니다.

  1. **대시보드 메뉴:** 왼쪽 사이드바에서 **Dashboards** 를 클릭합니다.
  2. **임포트 화면:** 우측 상단의 **[New]** 버튼을 누르고 **[Import]**를 선택합니다.
  3. **Hub ID 입력:** 'Import via grafana.com' 입력창에 아래 ID 중 하나를 입력하고 **[Load]**를 누릅니다. 
     * **ID: 4701** (JVM 기반 Spring Boot 모니터링에 가장 대중적인 템플릿)
     * **ID: 11378** (좀 더 세련된 디자인의 모니터링 대시보드)
  4. **데이터 소스 매핑:** 화면 하단 'Prometheus' 선택박스에서 아까 생성한 **Prometheus** 데이터 소스를 선택합니다.
  5. **완료:** **[Import]** 버튼을 누르면 즉시 시각화된 대시보드가 나타납니다.

### 3\. 프로메테우수와 Grafana를 docker compose를 통해서 동시에 실행하여 관리 . 
    
    
    version: "3"
    
    services:
      prometheus:
        image: prom/prometheus
        container_name: prometheus
        ports:
          - "9090:9090"
        volumes:
          - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
        restart: always
    
      grafana:
        image: grafana/grafana
        container_name: grafana
        ports:
          - "3000:3000"
        restart: always
